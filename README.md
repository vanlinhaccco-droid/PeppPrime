# PEPPA AIM

Standalone SwiftUI iOS app that displays a customizable crosshair inside the app.

## Requirements
- Xcode 16 or newer recommended
- iOS 18.0+
- Swift 6 / SwiftUI

## Open
1. Open Xcode on macOS.
2. Create a new iOS App project named `PEPPA AIM`, SwiftUI + Swift.
3. Replace the generated Swift files with the files in `PEPPA_AIM/Sources`.
4. Set the deployment target to iOS 18.0 or newer.
5. Select an iPhone simulator or a connected iPhone and Run.

This app is standalone. iOS does not allow an ordinary app to draw an arbitrary overlay over other apps.
